# scripts — agent guide

Shell and Node scripts with no shared subject, so this guide imports nothing. Read the decision
file for the script you are changing:

- `check-release-clean.sh` — `docs/decisions/release.md`.
- `check-client-names.sh`, `check-commit-identity.sh` — `docs/decisions/repository.md`, and No
  client names in the root `AGENTS.md`.
- `check-web-static.js`, `lib/` — `docs/decisions/web-ui.md` and `docs/decisions/shared-rules.md`
  (the mirror cases).
- `render-web-ui.js` — `docs/decisions/web-ui.md`.
- `render-web-ui-archive.js` — `docs/decisions/exports.md` and `docs/decisions/web-ui.md`.
- `measure-web-ui.js` and its `lib/*-cases.js` — `docs/decisions/web-ui.md`. `lib/ingest-client.js`
  speaks the wire in `docs/schema.md` → Wire protocol, to 127.0.0.1 only and with `.invalid` hosts.

## Key files

| Path | Why it matters |
|---|---|
| `scripts/check-release-clean.sh` | Production-safety enforcement. |
| `scripts/check-web-static.js` | The web checks that need nothing running: network call sites, the stylesheet audits, the JSON parser and every mirror case. First step of the CI `web` job. |
| `scripts/render-web-ui.js` | The live web UI's check; run it after touching `web/`, along with the archive probe below. CI runs both against a fixture session and pins how many checks pass. |
| `scripts/measure-web-ui.js`, `lib/measure-*.js` | The web UI in headless Chrome: the scope bar on top, path stations landing below the sticky box, each waterfall stub saying "calls not loaded" or "no calls" by what the whole-session copy holds, and each group with calls counting "calls loaded" and saying "older calls not loaded" only where the copy holds older ones, a run toggle or a live row leaving a scrolled pane where it is, the top bar's count staying whole, in every wording, at 1000, 975, 800, 600 and 400 px (`lib/topbar-cases.js`), the shell at 1440, 1000, 600 and 400 px — the bar, its controls, the picker's start time, every view reachable, the rail and each page fitting, the Findings page on the payments session and, on the probe session, every masked hint whole and the dismiss form fitting, served and exported (`lib/measure-cases.js`), and the Stats page's route cells breaking only at a `.`, `:` or `/` at 400 px, served and exported (`lib/shell-cases.js`) — the list's room: the closed drawer out of Tab's reach and the page's width, rows at 400 px (the payments session's findings badges among them), the bands above the list, the toolbar on one row, the divider dragged, the overview hint whole and each view opening where it was left (`lib/list-room-cases.js`) — the polish rules: every icon control a target of at least 24×24 px hit at its centre, at 1440, 1000 and 400 px, served and exported, dark and light, and on the Stats, Findings, Diff, Sessions, Processes and Settings pages every button at least 24 px tall, notes at most 72ch, the density select and each Sessions row's start time whole, every Stats and Diff table box as tall as its table, what a click draws on Diff and Findings (a route's detail, `clear filter`, the dismiss form, `restore`) at least 24 px tall, the key legend `?` opens on Settings inside the window at 1440 and 400 px, and `#/txn`'s `← traffic` is inside the window, hit at its centre and leaves the page when clicked, at 1440 and 400 px, served and exported (`lib/polish-cases.js`) — live traffic streamed into a daemon of its own through `/ingest` (`lib/ingest-client.js`), judging the filtered re-read's burst bound and its filter-edit and session-switch races, and the live redraw's signal, marker and call bursts and a lone call's delay on the waterfall and the path (`--only traffic`, `lib/live-traffic-cases.js`) — and first rows on a 160,000-call session — and the landing page, `site/index.html` from disk with no daemon, no wider than a 400 px window with every card's bullets inside it, nor than any window from 360 to 1440 px (`--only site`, `lib/site-cases.js`; CI's `web` job runs it on the runner's Chrome). These are what jsdom cannot see. Opt-in, `--only sheet --out <dir>` writes the contact sheet: a PNG of every page and traffic view, the Findings page on the payments session, a call's detail and `#/txn`, at 1440, 1000, 600 and 400 px, dark and light, served and exported, and an `index.html` grid of them, judging nothing (`lib/sheet-cases.js`). Run it once per web fix round; `--base <dir>` prints what moved against another tree. Needs Chrome, JDK 21 and a built daemon (`--only site` needs only Chrome); it serves each tree's `web/` ahead of the jar's, so a web edit needs no rebuild. |
| `scripts/qa-snapshot.sh` | Copies committed revisions into a fresh temp directory for side-by-side review, deleting nothing. Reviewers use it instead of a hand-written loop, which needed an approval click even in bypass mode; see `docs/TEAM.md`, "Snapshots". |
| `scripts/render-web-ui-archive.js` | Opens an exported session's HTML with the network forbidden and checks it works offline. Run it after touching `web/`: any new request that bypasses `source` fails it. |
