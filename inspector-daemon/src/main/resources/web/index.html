        Stats

        Sorting and opening a route's calls need the daemon — this is an exported session.

        Routes group paths by template: numeric, UUID, long hex and long base64-like segments read as {id}. If two paths are grouped wrongly, add a template to routeTemplates in config.json; it applies when the daemon restarts.

        Sessions

        Every run of the app is a folder under <data dir>/sessions. Deleting one is permanent — there is no trash — and a session the app is still writing to is never removed, because pulling the folder out from under an open writer loses the traffic on screen.

        MCP server

        Speaks over stdio, so your editor starts it — there is nothing here to start, and a process this daemon spawned would have no client on its pipes. Test proves the binary answers. Kill a wedged one in the list above and your editor spawns a fresh one.

        Repeated requests
        
      
        
        Highlights requests sent more than once, close together, by separate calls — same
        method, URL, status and byte counts. Retries and redirect hops share one call id and are
        never flagged; they already show as an attempt chain. Set to 0 to turn it off.
        Kept in this browser.
      
        
      
        
        
        
      
        
    
        

    
        
      
        Endpoint shortcuts
        
      
        
        One chip per distinct last path segment, most-used first —
        /v3/accounts/profile/status becomes status. Clicking one
        filters to path:*/status, a glob anchored at the end of the path, so
        profile does not also match profile/status. Built from the whole
        session rather than the filtered view, so the chips stay put once you click one. Set to
        0 to hide them. Kept in this browser.
