    Inspector processes on this machine

    Matched by launch arguments, not by name. A pkill -f inspector also kills your editor's MCP connection, and pkill -f "inspector.*serve" does too — the classpath contains ktor-server-cio. This list cannot make either mistake.

    Repeated requests

    Highlights requests sent more than once, close together, by separate calls — same method, URL, status and byte counts. Retries and redirect hops share one call id and are never flagged; they already show as an attempt chain. Set to 0 to turn it off.

    Endpoint shortcuts

    One chip per distinct last path segment, most-used first — /v3/accounts/profile/status becomes status. Clicking one filters to path:*/status, a glob anchored at the end of the path, so profile does not also match profile/status. Built from the whole session rather than the filtered view, so the chips stay put once you click one. Set to 0 to hide them.

    MCP server

    Speaks over stdio, so your editor starts it — there is nothing here to start, and a process this daemon spawned would have no client on its pipes. Test proves the binary answers. Kill a wedged one in the list above and your editor spawns a fresh one.
